# Contributing

Thanks for helping. Issues and pull requests are welcome on the client libraries, the examples and the spec.

- **Bug or missing feature:** open an issue with what you expected and what happened.
- **Pull request:** keep it small and focused, and run the tests (`npm test` or `python -m unittest discover -s tests`).
- **Security problem:** never in a public issue. Write to team@opaq.computer (see [SECURITY.md](SECURITY.md)).
